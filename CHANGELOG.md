# Changelog

All notable changes to `recallwatch` are documented here.

## v0.1.3 — 2026-09-24

- Add release-history documentation and repository-contract checks for required project files, README links, CI release artifacts, CodeQL, and version/changelog parity.
- Include changelog, workflow metadata, tests, and README files in source distributions via `MANIFEST.in`.

## v0.1.2 — 2026-09-24

- Modernize packaging license metadata to SPDX form.
- Add regression tests for package metadata and version consistency.
- Verify local tests, package build, CLI version output, and GitHub Actions CI.

## v0.1.1 — 2026-09-24

- Maintenance release with package build artifacts and checksums for the current CLI/test suite.

## v0.1.0 — 2026-09-24

- Initial public release of segmented ANN recall drift monitoring.
- Provide synthetic-vector snapshot generation, `.npy` input support, per-segment diffing, and a deterministic random-projection LSH reference index.
